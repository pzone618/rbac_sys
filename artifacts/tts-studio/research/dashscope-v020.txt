### MultiModalConversation.call

Source: https://github.com/dashscope/dashscope-sdk-python/blob/main/_autodocs/api-reference/multimodal_conversation.md

Synchronous class method that invokes a multimodal conversation with a DashScope model. Accepts messages with image, text, audio, and video content, plus sampling and feature controls. Returns a MultiModalConversationResponse or a generator of responses when streaming.

```APIDOC
## MultiModalConversation.call

### Description
Synchronous class method to call a multimodal conversation model. Accepts multimodal messages (image, text, audio, video), sampling parameters, and feature flags. Returns a response object or a stream of response chunks.

### Method

### Behaviour notes

- Local files in user content (`{"image": "file:///..."}` etc.) are auto-uploaded to OSS via `preprocess_message_element` (`dashscope/utils/oss_utils.py`); when any upload happens the header `X-DashScope-OssResourceResolve: enable` is added.
- Same `ParamUtil.should_modify_incremental_output` merge logic as Generation: when streaming with `incremental_output=False` on merging models, chunks are accumulated with `merge_multimodal_single_response` (`utils/message_utils.py`) and signalled via `user_agent` parameter `incremental_to_full/{flag}`.
- Local files must be reachable by the SDK; remote HTTP(S) URLs are passed through unchanged.

### Return type

`MultiModalConversationResponse` (`dashscope_response.py:257`) — `output` is `MultiModalConversationOutput` with `choices`, `audio`; `usage` is `MultiModalConversationUsage` (`input_tokens`, `output_tokens`, `characters`). Streaming yields `MultiModalConversationResponse` chunks.

### Examples

```python
from dashscope import MultiModalConversation

resp = MultiModalConversation.call(
    model="qwen-vl-plus",
    messages=[{
        "role": "user",
        "content": [
            {"image": "https://example.com/cat.jpg"},
            {"text": "What breed is this cat?"},
        ],
    }],
)
print(resp.output.choices[0].message.content[0]["text"])
```

Audio-video input with error handling:

```python
from http import HTTPStatus
from dashscope import MultiModalConversation

resp = MultiModalConversation.call(
    model="qwen-vl-max",
    messages=[{
        "role": "user",
        "content": [
            {"video": "https://example.com/clip.mp4"},
            {"text": "Summarize the video"},
        ],
    }],
)
if resp.status_code != HTTPStatus.OK:
    raise RuntimeError(f"{resp.code}: {resp.message}")
print(resp.output.choices[0].message.content)
```

### Message, Choice, and Audio classes

Source: https://github.com/dashscope/dashscope-sdk-python/blob/main/_autodocs/types.md

Defines Message, Choice, and Audio classes. Message.from_generation_response reads output["text"] to create an assistant Message, otherwise falls back to output.choices[0].message (returns None if no choices). Choice.__init__ coerces message dicts into Message instances.

```python
class Message(DictMixin):
    def __init__(self, role: str, content: Union[str, List] = None, **kwargs)
    @classmethod from_generation_response(cls, response: DictMixin)   # -> Message | None
    @classmethod from_conversation_response(cls, response: DictMixin) # alias
```

```python
@dataclass(init=False)
class Choice(DictMixin):
    finish_reason: str
    message: Message
```

```python
@dataclass(init=False)
class Audio(DictMixin):
    data: str; url: str; id: str; expires_at: int
```

### Audio

Source: https://github.com/dashscope/dashscope-sdk-python/blob/main/_autodocs/types.md

Represents audio data in a response. It contains the audio data, URL, ID, and expiration time.

```APIDOC
## Audio

### Description
Represents audio data in a response. It contains the audio data, URL, ID, and expiration time.

### Fields
- **data** (str) - The audio data.
- **url** (str) - The URL of the audio.
- **id** (str) - The ID of the audio.
- **expires_at** (int) - The expiration timestamp.

### MultiModalConversation / AioMultiModalConversation

Source: https://github.com/dashscope/dashscope-sdk-python/blob/main/_autodocs/api-reference/multimodal_conversation.md

Multi-modal (vision, audio, video, omni, TTS voice) conversational calls to Qwen-VL / qwen omni models.

- Module: `dashscope/aigc/multimodal_conversation.py`
- Exported: `dashscope.MultiModalConversation`, `dashscope.AioMultiModalConversation` (also from `dashscope.aigc`)

Class attributes: `task = "multimodal-generation"`, `function = "generation"`, nested `Models.qwen_vl_chat_v1 = "qwen-vl-chat-v1"`.
