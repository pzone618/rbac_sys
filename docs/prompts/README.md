# 工程生成提示词

本目录保存可复用的工程生成契约和经过验证的实例化版本。提示词描述的不只是功能范围，也包括安全、测试、部署、跨平台启动和验收要求。

## 文件职责

- `rebuild-rbac-system-v1.md`：权威通用模板。新增或修正规则时优先修改此文件。
- `rebuild-rbac_sys-system-v1.md`：以 `rbac_sys` 参数实例化的参考版本，用于生成当前工程和核对模板展开结果。

两份文件当前均为 v1.12。实例化文件不能反向成为另一套独立规范；通用要求发生变化时，应同步更新模板、实例和版本记录。

## 使用流程

1. 复制通用模板，并完整填写 `template_inputs`，不得猜测工程名、namespace、hostname 或端口。
2. 将所有 `{{...}}` 占位符替换为经过校验的值，同时保留模板规定的派生关系和九端口登记。
3. 使用 Context7 核对会随版本变化的框架和工具用法；不可用时记录原因并改查官方文档。
4. 检查生成物中没有残留占位符、示例工程名、未登记端口或跨工程资源名。
5. 同步更新变更记录，并验证 Markdown 代码围栏、UTF-8 编码和安全约束。

提示词、README 和示例配置只能记录凭据变量名、来源与安全取值方法，禁止写入真实密码、token、私钥或完整含凭据连接串。
